ТЕХНО — интерактивный журнал (HTML/CSS/JS, один файл)

ФАЙЛЫ
  index.html  — финальная версия (листание страниц пальцем, 1 страница на
                телефоне вертикально, разворот из 2 страниц горизонтально)
  arhiv/      — ранние версии (для истории)

КАК ОТКРЫТЬ
  Дважды щёлкните index.html — откроется в браузере.
  Нужен интернет только для шрифтов (без него будет запасной шрифт).

КАК ОПУБЛИКОВАТЬ НА GITHUB PAGES (для QR-кода)
  1. github.com -> New repository (имя, например, konkurs), Public.
  2. Загрузите index.html в репозиторий (Add file -> Upload files).
  3. Settings -> Pages -> Source: Deploy from a branch -> main, / (root) -> Save.
  4. Через 1–2 минуты ссылка: https://ВАШ-ЛОГИН.github.io/konkurs/
  5. По этой ссылке делайте QR-код. Репозиторий не удалять до конца конкурса.

КАК МЕНЯТЬ СОДЕРЖАНИЕ
  Страницы — это блоки <section class="pg"> внутри <div id="src">.
  Первый и последний блок (class="pg cv") — обложки. Всего чётное число
  страниц (сейчас 12). Если добавляете страницы, добавляйте парами.
